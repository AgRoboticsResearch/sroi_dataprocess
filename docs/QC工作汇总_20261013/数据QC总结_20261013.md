## 模块 1：轨迹人工 QC（2026-10-11）

**方法**：梯形掩膜 SLAM 轨迹经外参投影回首帧 RGB（`projection_qc_batch.py`，1138 张），
人工逐张审查。
**标准**：①首帧画面必须出现草莓（轨迹应从果出发）②轨迹终点下方必须有果
（真的到达采摘位；多果场景放宽任一果即可）。
**筛掉**：轨迹恢复异常、采摘失败、误录。
**结果**：剔 20 条（1.8%），清单在 `轨迹QC/剔除清单_EXCLUDED.md`（本汇总目录内）。

## 模块 2：夹爪动作恢复 v2（2026-10-12 ~ 13，全量重跑）

**旧流程**：全横带检测双 tag（ID 不分位置）→ episode 级对称中心 → 镜像补全 →
尖峰剔除 → forward-fill 补洞 → episode 级 min-max 归一化。
**旧问题**：错侧/误检 ID 直接进序列成尖峰；丢检段前值填充成楼梯；强光/阴影整段丢失；
归一化锚点逐条漂移。

**新流程**（`gripper_tag_core.py`，session 级两遍架构）：

| 步骤 | 做什么 | 目的 / 筛掉什么 |
|---|---|---|

| 0' 预处理链 | raw → CLAHE → 直方图均衡，只补缺帧 | **救强光/阴影帧**（好帧零开销） |
| A 先验粗筛 | 双 tag 中点须在 320±12px | **滤噪声配对**（存在性筛选） |
| A' 实测中心 | 幸存中点 session 池化中位数（A 簇 324.5 / B 簇 328.8） | 单 tag 镜像推算用实测中心，亚像素且跨条稳定 |
| A'' 距离绝对界 | 距离 ∈ [78,267]px（36 条标定 ±5px），双 tag 距离与镜像距离都查 | **滤物理不可能值** |

None 而非旧方案的错误前值填充、强光全救回）。

## 模块 4：开头准静止段裁剪（转换器内嵌，`sroi_to_lerobot.py`）

**问题**：录制开头手持悬停抖动+晃悠漂移，旧训练集 100% 保留（本期量化：~13.7% 帧）。
**迭代**（三轮，每轮被下一轮的数据推翻）：
1. 滑均速度 <0.3mm/帧 → 漏裁：原地晃悠的路径速度照样超标；
2. 净位移 ≥5mm → 误触发：「晃悠+漂移」形态（步长 0.4-0.6mm、方向乱、净漂 5-12mm）在 5mm 就触发，把悬停当运动；
3. **夹角回推（定稿）**：10mm 净位移锚点 → 回推要求步长 ≥0.8mm 且相邻步夹角 <10° →
   首个不合格帧为起点；30% 保险帽。方向一致性是区分振荡悬停与趋势运动的最强信号。

**数字**：中位 10 帧 / 合计 14064 帧（13.7%）/ 145604 最重（中位 26）/ 153147、153907 最轻（5）。
裁剪溯源在数据集 `meta/start_trim.json`。
